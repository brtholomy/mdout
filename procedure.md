# 1. Run the script

run from project root:

```sh
./mdout/run.sh foo.md
```

# 2. Copy into AFP

1. Copy from docx.

2. Into one normal page master.

3. Expand to all pages.

4. Remove all styles

5. Apply Body to everything

6. Chapter title master

7. Chapter title style

8. Drop caps to first paragraph

NOTE: when mass copying, stop and iterate at this point.

# 3. Search and replace in AFP

1. Delete unused styles.

2. Run find-and-replace for all special chars and their associated style as outlined below.

## Find and apply auto_numbered_section

```
¢
\1
```

## Find and apply list long

```
 •	(.*?)
\1
```

### Apply list short

Mark in source with:

```
<!-- FORMAT: list short -->
```

NOTE: I may forgo the short versions of lists. It's a nuissance and not strictly necessary.

## Find and apply numbered list long

```
 [0-9]+?\.\t
\1
```

### Apply list numbered short

Mark in source with:

```
<!-- FORMAT: list numbered short -->
```

## Find and apply blockquote

```
¥
\1
```

### Find and apply blockquote source

```
₱
\1
```

### Apply blockquote poem

Mark in source with:

```
<!-- FORMAT: blockquote poem -->
```

OPTIONAL: right align short blockquote poem instances.

## Fix "Verbatim Char" which ODT/DOCX will insert

replace with "inline code" char style

NOTE: for blockquote sections, these are either English in Body or Chinese.

## Find and apply `<sup>`

```
¤
\1
```

NOTE: failed to show up for some reason, `<sup>` tag proceeds through rich text formatting though.

## Find and apply `<h2>`

```
£
\1
```
